Off-Site Backups

Automatically uploads an encrypted copy of the database to Backblaze B2 every night, separate from this app's own storage — so a problem with this app's hosting can't take the only copy of the data down with it. The database is encrypted with a passphrase before it ever leaves this app, so the B2 account alone can't read it.

In the Render dashboard: this service → Environment → Add Environment Variable, key BACKUP_PASSPHRASE. Also worth saving a copy in a password manager, since Render access is still the one remaining single point of failure for it.
